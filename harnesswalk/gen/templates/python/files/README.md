# @@title@@ harness

A plain-Python harness you own, with no runtime dependency on Harnesswalk: generated by
`harnesswalk init --profile @@profile@@ --pack @@pack@@`, it needs Python 3.12 and `pyyaml`,
and nothing else at run time.

It is the `@@profile@@` rung of the Harnesswalk ladder: the gateway, the context builder, the
loop, the model layer, the tools and the trace, plus the controls this rung switches on. Every
node the profile switches off is still visited as a skipped span, so the Harnesswalk web app
draws the same diagram with those nodes dimmed.

## Run it

```sh
make setup                      # .venv with pyyaml and the test tools
make eval                       # the pack's golden set on the fake provider
make conformance                # the Harnesswalk conformance suite under @@profile@@
make serve                      # the HTTP API on 127.0.0.1:8000 (fake provider)
make serve PROVIDER=@@provider@@        # the same on the real model
make turn MSG="..." FIXTURE=<a fixture in packs/@@pack@@/fixtures/fake>
```

To watch it in the Harnesswalk web app: in a Harnesswalk checkout, run
`HARNESSWALK_API_URL=http://127.0.0.1:8000 make web-dev` and open http://127.0.0.1:5173.
GENERATION_NOTES.md lists the HTTP routes this repo serves.

## What is yours and what is managed

`harness/core/` and `tests/conformance/` are managed: `harnesswalk upgrade` three-way merges a
newer template set into them on a new branch, keeping your edits (conflicts are marked and
listed). Everything else is yours and is never touched: `prompts/`, `skills/`, `policy/`,
`tools/`, `packs/`, `config/`, `evals/`, this README. `harness.lock` records the template set
(@@template_version@@) and spec (@@spec_version@@) versions and a hash of every file;
`.harnesswalk/pristine/` keeps the managed files as generated.

## Proving it

`make conformance` runs the Harnesswalk conformance suite (vendored in `tests/conformance/`)
against this repo over HTTP: every case whose `requires` this profile satisfies must pass.
Cases for nodes this rung switches off, and for public mode (never generated), are skipped
with the reason. `make conformance-model` runs the same suite on the real model; cases whose
fixture scripts tool calls are marked `scripted` there.
