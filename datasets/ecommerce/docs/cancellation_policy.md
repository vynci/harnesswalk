# Order Cancellation Policy

This policy explains when an order can be cancelled and what happens when it is. It is short on purpose, because the rule is simple: you can cancel while we have not shipped yet.

## When you can cancel

An order can be cancelled only while its status is processing. Processing means we have received and paid for your order but it has not left the warehouse. You can check your order status at any time with the assistant, using your order id, which looks like QF-20430.

An order that is shipped, delivered or already cancelled cannot be cancelled. If your order has shipped and you no longer want it, the right route is a return once it arrives. See the Returns and Refunds Policy for the 30-day window and the 6 dollar return label fee. Do not refuse delivery without contacting support first, because refused parcels can take longer to process.

## Approval

Cancelling an order is a destructive action, because it cannot be undone. Every cancellation therefore needs an approval from a member of the support team before it runs. When you ask the assistant to cancel, it checks the status first, then asks for the approval and tells you it has done so. It will only say the order is cancelled once the system confirms it. If the approval is declined, nothing changes and the order carries on to shipping.

## What you get back

When a cancellation goes through, the full amount of the order is refunded to the original payment method. The refund arrives in 5 business days. No cancellation fee is charged and no return label is needed.

## Changing an order instead

If you ordered the wrong size or colour, the quickest fix is often to cancel the processing order and place a new one. We cannot edit the contents of an order after it is placed. Because stock is limited for some items, place the new order promptly.

## Orders that ship quickly

Orders using express shipping move from processing to shipped faster, sometimes within a few hours of being placed. If you want to cancel an express order, contact the assistant straight away. Support hours are Monday to Saturday, 8:00 to 20:00 Eastern, and orders placed outside those hours may still be cancellable when we open.

## Gift cards

If you paid part of an order with a gift card, the gift card portion goes back onto the gift card. Gift cards cannot be refunded to cash.
