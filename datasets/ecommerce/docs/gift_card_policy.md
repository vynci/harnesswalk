# Gift Card Policy

Quillfern Outfitters gift cards are a simple way to give someone the gear they want, without guessing a size or a colour. This page explains the amounts, how to use a card and what happens if one goes missing.

## Card amounts

Gift cards are sold in three fixed amounts: 25, 50 and 100 dollars. Several cards can be bought in one order if you want to give a larger amount. Each card has its own code and balance, and a recipient can use more than one card on a single purchase.

## No expiry

Gift cards never expire. There are no inactivity fees, service charges or monthly deductions. A card bought today can be used next year, with the full balance intact.

## How to use a card

Enter the card code at checkout. If the card balance is less than the order total, the balance is applied first and you pay the rest with another payment method. If the balance is greater than the order total, the remainder stays on the card for later. You can check your balance by contacting support with the card code.

## What cards cannot do

- Gift cards cannot be redeemed for cash.
- Gift cards cannot be refunded to cash after purchase, so please choose the amount with care.
- Gift cards cannot be used to buy other gift cards.
- A card cannot be combined with a price adjustment on the same item.

## Refunds paid onto gift cards

If an order was paid for with a gift card, any refund for that order goes back to the same card, not to another payment method. This keeps the money where it came from and also applies to cancelled orders.

## Lost or stolen cards

If a card is lost, contact support during opening hours with proof of purchase, such as the order id from the original purchase. If the card still has an unused balance, the team can issue a replacement card for that balance. Replacement is not possible if the code has already been used.

## Cards received as a gift

A recipient does not need to create an account to use a card. The code is valid for any order placed on the shop. If the code does not work, check for a typing error, then contact support with the code and the order id if you have one.

## Fraud and safety

Treat a gift card code like cash and never share it with someone you do not trust. Support will never ask you to read a gift card code out for a payment outside the shop. If you think a code has been used without your knowledge, contact support at once.
