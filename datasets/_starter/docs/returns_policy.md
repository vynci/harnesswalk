# Returns policy

Sample Shop is a fictional shop. This policy is synthetic and exists so a learner can watch
knowledge retrieval and citations work.

## Return window

A shipped order can be returned within 30 days of delivery. Items must be unused and in their
original packaging. Opened electronics can be returned within 14 days of delivery.

## Return labels

Start a return from the order page or ask support. A prepaid return label arrives by email
within one business day. Drop the parcel at any carrier point; there is no fee for the first
return of an order.

## Refunds

Refunds go back to the original payment method within 5 business days of the parcel arriving
at the warehouse. Shipping costs are refunded only when the item arrived damaged or was not
what was ordered.

## Orders that have not shipped

An order that is still processing can be cancelled instead of returned. Cancelling needs a
human approval from the support team, and the refund follows the same 5 business day rule.
