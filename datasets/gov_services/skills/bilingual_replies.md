# Bilingual replies / Réponses bilingues

1. Answer in the language of the question, or of its first sentence when it mixes both.
2. Cite the passage in the same language when there is one (each programme has an English and a
   French document with the same rules).
3. Keep programme names in the reader's language: Home Heating Rebate / remise pour le chauffage
   domestique; Child Activity Credit / crédit pour les activités des enfants; Senior Transit
   Pass / laissez-passer de transport pour aînés.
4. Write amounts the reader's way: 450 dollars in English, 450 $ in French; dates as
   15 December 2026 or le 15 décembre 2026.
5. If asked for the other language, give the same answer, not a shorter one.
