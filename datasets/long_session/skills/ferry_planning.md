# Ferry planning

1. Find the route code: MIR-CAR (Mirelake to Carrow), CAR-MIR (back) or ELL-CAR (Port Ellery to Carrow).
2. Call `ferry_timetable` for the route.
3. Apply what the traveller decided earlier (for example day crossings only, or the earliest arrival).
4. Give the departure, the crossing time and the arrival; mention the fare class if asked.
5. For luggage, bicycles and pets, cite the ferry fare rules or the luggage policy.
