# Office Wifi Guide

Pebblebrook Studio runs three kinds of wifi across its offices: the staff network, guest networks at each office, and the connection that the IT desk uses for its own equipment. This guide explains which network to use, how the guest code works, and what to try when the wifi drops.

## The staff network

Company laptops and phones should join the staff network called Pebble-Staff. It is the same name in the north, harbour and east offices, and it is the only network that can reach the internal file share and the printers without going through the VPN. Staff devices join it automatically once they have been enrolled by the IT desk, so you should not need to type anything in.

If your laptop does not join Pebble-Staff on its own, check that you are not connected to a guest network by mistake. Open the wifi menu, choose Pebble-Staff, and sign in with your account. If the sign-in is refused, see the password guide: the account may be locked for 15 minutes after several failed attempts, and it unlocks by itself after that time.

Personal devices should not be added to the staff network. Use a guest network for them instead.

## The guest networks

Each office has its own guest network, so that visitors and personal devices stay separate from company systems:

- north office: Pebble-Guest-North
- harbour office: Pebble-Guest-Harbour
- east office: Pebble-Guest-East

Guest networks give internet access only. They cannot see printers, the file share or internal web apps, and that is intentional. If a visitor needs a printer, send the file to them by email or a shared link instead.

## The guest code

Every guest network asks for a code. The code is printed on the reception card at each office's front desk, and it changes every Monday morning. This means a code written on a whiteboard or sent in an old message will stop working at the start of a new week. If the code is refused, ask at the reception desk for the current card rather than guessing.

Do not give the guest code to anyone who is not visiting the office. The code is a convenience for visitors and is not a security control for staff devices.

## When the wifi drops

Most drops last only a few seconds while a laptop moves between access points, and nothing needs fixing. If the connection stays down, try these steps in order:

1. Turn wifi off and on again on your device.
2. Forget the network and join it again, entering the code or your account details.
3. Restart the device. This clears a stuck network address in most cases.
4. Check whether the problem affects everyone. If colleagues on the same network also have no connection, the access point near your desk may be the cause.

If none of these help, open a ticket through the support form and say which office you are in, which network you chose, and whether the problem happens in one room or everywhere. The desk answers new tickets within 4 working hours. If you are working from home, use the VPN and the web apps rather than the office networks.

Wifi work in the offices is scheduled with notice. The access points in the north and harbour offices were last updated in late October, and the east office has an access point that is checked during the Wednesday technician visit.

## Keeping the network safe

Lock your screen when you leave your desk, even briefly, and never share the staff password with a colleague. If a message asks you to join an unknown network or to type your account details into a page you did not expect, do not do it. Report it through the support form instead.
