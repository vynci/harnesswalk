# File Share Guide

The file share is where Pebblebrook Studio keeps its project folders, shared templates and client material. It is available from every office, and from home over the VPN. This guide explains how to reach it, how the nightly backup works, and how to get back a file you have deleted.

## Reaching the file share in the office

When you are on the staff network (Pebble-Staff), the file share appears in your file manager without any extra step. In most systems it shows as a drive or a network location called the Studio share. Open it, and you will see the project folders you have been given access to. If a folder you need is missing, ask your manager to request access through the support form; the desk does not grant folder access on the spot.

Guest networks cannot see the file share. If you are a visitor who needs a file, your host should share it with you by a link.

## Reaching the file share from home

From home, connect to the VPN first. The VPN app reconnects by itself if the network drops, so you should not need to start it again each time. Once connected, the file share appears in the same place as it does in the office.

Two things to keep in mind. First, the VPN must be up before you open the share; a half-connected VPN can make the share look empty. Second, if the VPN is down for maintenance, you can still reach the web apps for most day-to-day work. Check the service status page or ask the desk before assuming the share is broken.

## Nightly backup

The file share is backed up every night between 01:00 and 02:00. The backup runs in the background, and the share stays usable during it, but files saved between 01:00 and 02:00 may take a little longer to appear in the backup. You do not need to take any action for the backup to run.

Keep the backup in mind when you plan large changes. If you are about to rename or move a big folder, doing it in the afternoon means the nightly backup captures the new layout on the same day.

## Restoring a file you have deleted

Deleted files can be restored for 30 days. This covers files you removed by mistake, files overwritten with a bad version, and files removed when a project was tidied up.

To restore a file, open the Studio share, go to the folder the file was in, and look for the restore option in the folder history. Choose the version from the day before the problem and copy it back. If you cannot find the file, or the folder itself is gone, open a ticket through the support form and give the folder name, the rough date you last saw the file, and the project it belonged to. The desk answers new tickets within 4 working hours.

Files older than 30 days cannot be restored from the share. If you need something from further back, say so in the ticket; the desk will check whether a copy is held elsewhere before saying it is gone.

## Good habits

Save work to the share rather than to your laptop's desktop, so that the nightly backup covers it. Avoid keeping the only copy of a file on a memory stick, and never plug in an unknown USB stick to copy files; use the share instead. If a file behaves oddly, such as opening as an empty document, stop editing it and open a ticket before the problem spreads to other copies.
