# Fund documents (always cite)

1. Work out which fund or policy the question is about. Fund fact sheets cover strategy, vintage, size, fee, carry, hurdle and term. Policies cover transfers, default and late payment, reporting and notice delivery.
2. Search the knowledge passages. If a passage looks cut off or the question needs the full page, call `read_doc` with the document id.
3. State the figure or rule in plain words and add the citation marker right after the claim, for example [1].
4. Cite only the passages you actually used. Never quote a fee, rate or date that is not in a retrieved passage.
5. If two funds are mixed up in the question, ask which one is meant before answering.
6. For defined terms (NAV, commitment, carry, hurdle, clawback, J-curve), use the glossary and cite it.
