# Answering hub questions

1. Work out the three-letter hub code. If the shipper gives a hub name, match it against KRN, MAV, HLM, TRB, WYN or ORS. If unsure, ask.
2. Call `hub_capacity` with the code.
3. Report the hub name, its status, the utilisation percentage, whether it accepts reroutes and the daily cutoff time.
4. If the status is `congested` or `closed`, say shipments may be held there and that a reroute into it is not possible.
5. For hub addresses, districts or opening patterns, search the knowledge base and cite the hub directory.
